# سیستم یکپارچه مدیریت سازمان (ERP/CCMS)

## 🖥️ الزامات سیستم

### نیازمندی‌های سرور
- **PHP**: نسخه 7.4 یا بالاتر (توصیه: PHP 8.1+)
- **MySQL**: نسخه 5.7 یا بالاتر / MariaDB 10.2+
- **Apache/Nginx**: با پشتیبانی mod_rewrite
- **حافظه**: حداقل 256MB RAM
- **فضای دیسک**: حداقل 500MB

### افزونه‌های PHP مورد نیاز
```
- PDO
- PDO_MySQL
- mbstring
- json
- openssl
- session
```

## 🚀 نصب و راه‌اندازی

### گام 1: دانلود فایل‌ها
```bash
git clone https://github.com/your-repo/esmartis-erp.git
cd esmartis-erp
```

### گام 2: ایجاد دیتابیس
```sql
CREATE DATABASE esmartis_erp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'esmartis_user'@'localhost' IDENTIFIED BY 'esmartis1364';
GRANT ALL PRIVILEGES ON esmartis_erp.* TO 'esmartis_user'@'localhost';
FLUSH PRIVILEGES;
```

### گام 3: پیکربندی
فایل `config.php` را ویرایش کنید و اطلاعات دیتابیس را تنظیم کنید:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'esmartis_erp');
define('DB_USER', 'esmartis_user');
define('DB_PASS', 'esmartis1364');
```

### گام 4: اجرای Migration
```bash
php dbi.php
php dbdef.php
```

### گام 5: تنظیم مجوزها
```bash
chmod -R 755 /path/to/erp
chmod -R 777 uploads/
chmod -R 777 logs/
```

### گام 6: دسترسی به سیستم
مرورگر خود را باز کرده و به آدرس سیستم بروید:
```
http://localhost/erp/
```

**اطلاعات ورود پیش‌فرض:**
- نام کاربری: `admin`
- رمز عبور: `654321`

⚠️ **هشدار امنیتی**: حتماً پس از اولین ورود، رمز عبور را تغییر دهید!

## 🔒 امنیت

### محافظت در برابر SQL Injection
تمام کوئری‌ها با استفاده از Prepared Statements اجرا می‌شوند:
```php
$user = db()->selectOne(
    "SELECT * FROM users WHERE username = :username",
    [':username' => $username]
);
```

### محافظت در برابر XSS
تمام خروجی‌ها با تابع `h()` Escape می‌شوند:
```php
echo h($user['username']);
```

### CSRF Protection
تمام فرم‌ها شامل CSRF Token هستند:
```php
<input type="hidden" name="csrf_token" value="<?php echo generate_csrf_token(); ?>">
```

### Session Security
- HttpOnly cookies
- Secure cookies در production
- Session timeout (1 ساعت)
- محدودیت تلاش ورود

### محدودیت تلاش ورود
- حداکثر 3 تلاش در 3 دقیقه
- لاگ تمام تلاش‌های ناموفق

## 🛠️ راهنمای توسعه

### افزودن ماژول جدید

1. **ایجاد جدول دیتابیس** در `dbi.php`
2. **افزودن مجوزها** در `dbdef.php`
3. **ایجاد فایل لیست** (مثلاً `mymodule.php`)
4. **ایجاد فایل فرم** (مثلاً `mymodule_form.php`)
5. **افزودن به منوی سیستم**

### قوانین Coding
- از camelCase برای متغیرها استفاده کنید
- از snake_case برای نام جداول و فیلدها استفاده کنید
- همیشه داده‌های ورودی را Sanitize کنید
- همیشه داده‌های خروجی را Escape کنید
- از تابع `db()` برای دسترسی به دیتابیس استفاده کنید
- هیچ کوئری SQL مستقیم خارج از `dbc.php` نباشد

### تابع‌های Helper مفید
```php
h($str)                      // Escape HTML
sanitize_input($data)        // پاکسازی ورودی
check_login()                // چک احراز هویت
check_permission($m, $l)     // چک مجوز
redirect($url)               // هدایت
show_message($msg, $type)    // نمایش پیام
en2fa($str)                  // تبدیل عدد به فارسی
fa2en($str)                  // تبدیل عدد به انگلیسی
```
