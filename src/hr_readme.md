## ⏰ حضور و غیاب

### ثبت حضور:
```
1. ثبت خودکار از دستگاه
   - اثر انگشت
   - کارت مغناطیسی
   - تشخیص چهره
   - رمز عبور

2. ثبت دستی
   - توسط مدیر HR
   - توسط مدیر واحد
   - ثبت گروهی
```

### محاسبات خودکار:
- ساعات کاری: 8 ساعت روزانه

- اضافه‌کاری: بیشتر از 8 ساعت
- نیمه وقت: کمتر از 4 ساعت

## 💰 محاسبه حقوق

### مراحل محاسبه:

#### 1. تعریف اطلاعات حقوقی:
```
- حقوق پایه
- مزایا (مسکن، ایاب و ذهاب، غذا، عائله‌مندی)
- کسورات ثابت (بیمه، مالیات)
```

#### 2. محاسبه خودکار:
```php
// حقوق ناخالص
$grossSalary = $baseSalary + $allowances + $overtime - $absentDeduction

// کسورات
$deductions = $insurance + $tax + $loan + $others

// حقوق خالص
$netSalary = $grossSalary - $deductions
```

#### 3. صدور فیش:
- فیش حقوقی قابل چاپ
- جزئیات کامل مزایا و کسورات
- امضای الکترونیکی

### فرمول‌های محاسبه:

**اضافه‌کاری:**
```
دستمزد ساعتی = حقوق پایه / (26 روز × 8 ساعت)
اضافه‌کاری = دستمزد ساعتی × 1.4 × ساعات اضافه‌کاری
```

**کسر غیبت:**
```
دستمزد روزانه = حقوق پایه / 26
کسر غیبت = دستمزد روزانه × تعداد روز غیبت
```

**بیمه (7%):**
```
بیمه = حقوق پایه × 0.07
```

```
1. کارمند درخواست می‌دهد
2. سیستم موجودی را چک می‌کند
3. مدیر مستقیم بررسی می‌کند

```

### محاسبه موجودی:
```

باقیمانده = موجودی اولیه - استفاده شده
```

## 🏦 سیستم وام

### انواع وام:
- وام قرض‌الحسنه
- وام ضروری
- وام مسکن
- وام آموزشی

### فرآیند:
```
1. درخواست وام
2. بررسی شرایط (سابقه کار، توانایی بازپرداخت)
3. تایید مدیریت
4. تعیین اقساط
5. کسر ماهانه از حقوق
```

### محاسبه اقساط:
```
مبلغ قسط = مبلغ وام / تعداد اقساط
شروع کسر = ماه بعد از تایید
پایان = تاریخ شروع + تعداد اقساط
```

## 📈 گزارش‌ها

### گزارش‌های آماده:

#### 1. گزارش پرسنلی:
- لیست کارکنان فعال
- کارکنان جدید
- استعفا/اخراج
- آمار به تفکیک جنسیت
- آمار به تفکیک سن
- آمار تحصیلات

#### 2. گزارش حضور و غیاب:
- حضور روزانه
- گزارش تأخیرات
- گزارش اضافه‌کاری
- گزارش غیبت
- نمودار حضور ماهانه

#### 3. گزارش حقوق:
- هزینه حقوق ماهانه
- تحلیل مزایا
- تحلیل کسورات
- مقایسه با ماه قبل
- پیش‌بینی هزینه

#### 4. گزارش مرخصی:
- مرخصی‌های در جریان
- موجودی مرخصی‌ها
- پرمرخصی‌ترین افراد
- نمودار مرخصی ماهانه

#### 5. گزارش وام:
- وام‌های فعال
- اقساط ماه جاری
- بدهی کل پرسنل
- تسویه‌های ماهانه
